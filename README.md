# Zyrax Drive

Drive around **Kian Zarandi**'s interactive 3D portfolio world.

Live: [kianpk.github.io/zyrax-drive](https://kianpk.github.io/zyrax-drive/)

## Controls

| Desktop | Mobile |
|--------|--------|
| WASD / arrows | Touch joystick |
| Shift = boost | Enter / interact near zones |
| M = map · L = mute | Quality defaults to Low on phones |

## What's inside

Project zones for TradeForge, VaultForge, Playfield, Orbit Desk, security labs, and more — all linked to `@kianPk` repos and demos.

## Stack

Three.js (WebGPU/WebGL + TSL) · Rapier · Howler · Vite  
Optimized build: compressed glTF/KTX textures, lowered pixel ratio, mobile quality tier.
